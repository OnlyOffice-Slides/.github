## About ONLYOFFICE Desktop Editors

ONLYOFFICE Desktop Editors opens documents, spreadsheets, and slides you already have or that you write yourself. It is an editor for those files on this PC. It does not include a library of other people's books or reports, and a file from a shared folder is still subject to whoever owns that folder.

Save your own copy before you revise a document someone else might still need unchanged. Track the file name. "Final" written three times is how the wrong version gets sent.

Export or save in the format the recipient can open. The program can stay closed after the file is saved. The document is the work, not the window.

## How to Use ONLYOFFICE Desktop Editors

1. Open a document you are allowed to change, preferably a copy if the original must stay intact.  
2. Edit the part you came for, not the whole layout, on the first pass.  
3. Save under a name that says the date or the version.  
4. Close and reopen the file to confirm the sentences you changed are really there.  
5. Send that file, not an unsaved window and not an older copy with a similar name.

## Troubleshooting

- The file opens read-only? You may not have rights, or it is open elsewhere. Save a copy if you are allowed to.  
- Formatting shifted? Check it before you send. Save as the format the other person uses.  
- You overwrote the only good copy? If you did not keep a version, the editor cannot invent the old text. Restore from your backup folder.
